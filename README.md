# sonarena

sonarena（ソナレナ）は、音源を空間に配置し、位置や広がりを調整して立体的な音響を作るツールです。単体で使うデスクトップアプリ版と、DAWで使うプラグイン版があります。

## ダウンロード

このリポジトリでは、アプリ版・プラグイン版の配布物と更新情報を公開しています。正式リリース中の対応OSは **Windows / Linux** です。配布ファイルは[リリース一覧](https://github.com/sonarena/sonarena-releases/releases)から、利用する製品とOSに合ったものを選んでください。

初めて使う方は、先に[操作マニュアル](https://note.com/royal_carp5294/n/nc72ec1e097b7)をご覧ください。

macOS版も公開を目指して開発・テストを続けています。現在テスト協力者を募集しています。参加を希望される方は、下記までご連絡ください。

## 製品

- **デスクトップアプリ版**：音源を配置・再生し、空間音響を音声ファイルに書き出せます。
- **DAWプラグイン版**：DAWのトラックに挿入して使えます。対応形式はCLAP / VST3です。

## リリースノート

### app-v1.0.0 — デスクトップアプリ版

- 複数の音源を読み込み、それぞれの位置や距離、広がりを設定できます。
- キーフレームやプリセットを使って、時間に沿った音の移動を作成できます。
- プロジェクトの保存と読み込みに対応しています。
- マイクやアプリの音をリアルタイムに定位できます。
- WAV、FLAC、MP3、FOA WAV形式での書き出しに対応しています。

### plugin-v1.0.0 — DAWプラグイン版

- DAWのトラックに挿入し、音源を空間に定位できます。
- 角度、距離、広がりを調整できます。
- CLAP形式とVST3形式に対応しています。
- パラメーターの時間変化はDAWのオートメーションで設定できます。

配布ファイルは[リリース一覧](https://github.com/sonarena/sonarena-releases/releases)から確認できます。
